# Assets

Assets de terceiros entram em `vendor/<provider>/<pack>/<version>/` somente após:

1. registro em manifesto;
2. cópia do arquivo de licença;
3. checksum do download original;
4. normalização e validação de tamanho.

Fontes aprovadas na baseline: KayKit, Quaternius e Kenney, preferencialmente CC0.
Consulte `Docs/ASSET_RESEARCH.md`.
